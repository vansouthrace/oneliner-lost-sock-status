An entry for the [make.fun bounty "Funniest Lost Sock Status Update"](https://make.fun/bounty/u-eager-stork-81-9647-funniest-lost-sock-status-update-4b1fa3ce): a single status update, max 120 characters, from a lost sock that ended up somewhere it should not be.

## The entry

> Status update: I eloped with a fitted sheet. We are happy. Do not look for me in the drawer.

## How to run

```sh
node main.ts
cat /output/entry.txt
```

`main.ts` writes the single entry line to `/output/entry.txt` and validates the 120-character gate before writing. Requires Node 22.18 or later (it runs TypeScript as-is).
